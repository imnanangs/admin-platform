# Admin Platform - NSDEV

Sebuah platform dashboard admin modern yang dibangun menggunakan **React 19**, **Vite**, dan **Tailwind CSS 4**. Proyek ini difokuskan pada estetika dan performa maksimal.

## 🚀 Tech Stack

- **Core:** [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Build Tool:** [Vite 6](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/), [HeroUI](https://heroui.com/) (dahulu NextUI), [Framer Motion](https://www.framer.com/motion/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand), [TanStack Query v5](https://tanstack.com/query/latest)
- **Testing:** [Vitest](https://vitest.dev/), [React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)
- **Utilities:** Axios, Zod, React Hook Form, Dayjs

## 📦 Instalasi

Pastikan Anda menggunakan [pnpm](https://pnpm.io/) sebagai package manager:

```bash
# Clone repositori
git clone [https://github.com/imnanangs/admin-platform.git](https://github.com/imnanangs/admin-platform.git)

# Masuk ke direktori
cd admin-platform

# Install dependensi
pnpm install

# Jalankan mode pengembangan
pnpm run dev
```
